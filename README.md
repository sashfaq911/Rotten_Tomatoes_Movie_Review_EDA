<h1 align="center">  Rotten Tomatoes Movie Review EDA </h1>

This mid-course data analytics project focuses on understanding how critics and audiences rate movies differently on Rotten Tomatoes.
The analysis simulates a real-world data request from a podcast host curious about trends in movie reviews.


## 📘 Project Description

Through structured data exploration, visualization, and statistical insight generation, the project reveals:

- Patterns in critic vs. audience ratings
- Genre-based performance trends
- Factors influencing high or low ratings
- Fun facts and correlations for engaging storytelling

The notebook demonstrates core data analytics competencies, including data cleaning, transformation, descriptive statistics, and visualization using Python.

## 🔍 Dataset
The datsaet used was provided by **[Maven Analytics](https://mavenanalytics.io/)**. 

## 🚀 Key Skills & Tools Used
- Python 🐍
- Pandas for data cleaning and exploration
- NumPy for numerical computation
- Matplotlib & Seaborn for data visualization
- Jupyter Notebook for analysis presentation
- Exploratory Data Analysis (EDA) methodology
  

## ✨ Project Highlights
- Analyzed a Rotten Tomatoes dataset with multiple rating metrics
- Compared audience and critic perspectives across movie genres
- Identified the most polarizing films (where audiences and critics disagree most)
- Created data visualizations illustrating rating distributions and trends
- Presented insights suitable for storytelling or podcast use


## 📈 Results & Insights
- Certain genres show systematic differences between critic and audience scores.
- High-budget or franchise films often score higher with audiences than critics.
- Critic scores tend to be more consistent, while audience ratings show wider variation.
- Strong correlation exists between critic consensus and total number of reviews.
